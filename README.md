# Emotion Detection Final Project

This project contains a Flask web application and Python package for emotion detection using IBM Watson Natural Language Understanding with a resilient offline fallback.

## Features
- Detects emotional intensity for anger, disgust, fear, joy, and sadness
- Provides a dominated emotion summary with percentage scores
- Includes a Flask UI for text analysis
- Handles blank input with a validation error
- Includes unit tests for the core package behavior

## Run locally
1. Create and activate a virtual environment
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python server.py`
4. Open the browser at `http://localhost:5000/`
